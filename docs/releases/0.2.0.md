# ModelCheck 0.2.0 release candidate

Status: prepared for review; not yet published to npm or announced as available.

## Release notes / launch copy

ModelCheck 0.2.0 adds a local regression workflow for AI applications. Write cases
for the behavior your application needs, save a baseline, change a model or
configuration, and get a PASS/WARN/FAIL verdict with inspectable evidence.

```sh
modelcheck init --provider openai --model YOUR_MODEL
# Set OPENAI_API_KEY in your environment and replace the example cases.
modelcheck baseline
# Change the target or runtime settings in modelcheck/config.yaml.
modelcheck verify --strict
modelcheck compare --candidate anthropic:YOUR_CANDIDATE
```

Cases are JSONL; configuration is YAML; the baseline is a reviewable
`modelcheck.lock`. Assertions cover schemas, exact/required/forbidden content and
tool-call constraints. Reports show quality changes, latency and estimated charge
with denominators and unavailable metrics clearly marked. JSON output and exit
codes support CI gates. Credentials stay in environment variables; cases go to
the provider you choose. Evidence is stored locally, with no ModelCheck server.

The existing capability-suite workflow remains available. See
[the changelog](../../cli/CHANGELOG.md) and
[the project CLI guide](../regression-cli.md) for compatibility and limitations.
